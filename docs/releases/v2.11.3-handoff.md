# NAIS blue v2.11.3 인수인계 보고서

작성일: 2026-08-11

릴리즈 태그: `v2.11.3`

대상 브랜치: `main`

## 1. 릴리즈 목적

이번 릴리즈는 NAIS blue의 기본 진입 경험을 도구 중심 UI에서 Guided QnA 워크플로우로 전환하고, 생성·관리·환경 구성 작업을 초심자가 Guided 화면을 벗어나지 않고 완료할 수 있도록 만든 프로덕션 릴리즈다. 기존 숙련자용 생성 셸은 우측 상단의 고급 생성 모드 진입점으로 보존한다.

## 2. 주요 변경 사항

### Guided 워크플로우

- 최초 진입점을 Guided 작업 홈으로 변경하고 A–E 작업 트리를 실제 실행 가능한 순차 워크플로우로 완성했다.
- 한 장 생성에는 모델, 프롬프트, 해상도, 생성 설정, 최종 검토, 결과 프리뷰 단계를 제공한다.
- 여러 장 생성에는 동일 설정 반복, 랜덤·순차 프롬프트 모듈, 씬 기반 생성, Guided 큐 관리를 제공한다.
- 프롬프트 작업에는 폴더별 모듈 선택·생성, 이미지/JSON 메타데이터 드래그 앤 드롭 및 파일 탐색기 가져오기를 추가했다.
- 프롬프트 다듬기, Style 비교, 로컬 AI 에이전트 템플릿 작업을 Guided 내부 단계로 구현했다.
- 라이브러리, 히스토리, 이미지 도구, 메타데이터, 휴지통, R2 업로드와 환경 설정 작업을 Guided 내부에서 수행하도록 구성했다.
- 상위 작업 트리와 각 세부 단계로 돌아갈 수 있는 내비게이션, 자동 저장 초안, 작업 재개, 결과 갤러리를 추가했다.

### 생성·비용·큐

- 사용자 지정 가로·세로 해상도를 지원하고 NovelAI 제한 범위와 64px 단위 정규화를 UI에서 검증한다.
- NovelAI 화면 관측값과 일치하는 해상도×Steps Anlas 계산식을 단일 비용 엔진에 반영했다.
- Guided 제출 시 표시 비용, 승인 상한, 실제 큐 스냅샷을 동일 계산 경계에서 재검증해 비용 동의 우회를 차단했다.
- 여러 NAI 토큰이 등록된 경우 토큰 슬롯별 병렬 실행을 허용하고, 같은 토큰 중복 슬롯과 스트리밍 작업은 안전하게 직렬화한다.
- Durable Queue 결과·실패·취소 상태를 Guided의 `내 작업`과 결과 화면에 지속적으로 투영한다.

### 보안·저장·플랫폼

- 데스크톱 NAI 자격 증명을 OS keyring에 저장하고 기존 평문 상태를 원자적으로 마이그레이션한다.
- 브라우저와 Android는 플랫폼 capability에 맞춰 현재 세션 메모리만 사용하며, 재시작 후 재입력이 필요하다는 문구를 명시한다.
- R2 설정은 자격 증명, 연결, 쓰기 검증을 통과해야 업로드할 수 있고 덮어쓰기는 명시적으로 확인한다.
- Style Lab 미리보기와 Guided 생성 모두 비용 동의·중복 제출 방지·불변 작업 스냅샷을 사용한다.

### UI/UX

- 전반적인 글자 크기와 행간을 조정하고 좁은 창·모바일에서 텍스트 잘림과 고정 높이 충돌을 제거했다.
- 프롬프트/씬/Style Lab의 카드형 UI를 얇은 구분선과 밑줄형 탭 중심으로 정리했다.
- Guided 배경 애니메이션, CTA 피드백, 반응형 작업 레일과 결과 프리뷰를 적용했다.

## 3. 호환성과 데이터

- 앱 식별자: `com.bluhair.naisblue`
- Windows 설치 제품명/실행 파일: `NAIS blue` / `Nais_blue.exe`
- Android: minSdk 24, targetSdk 36, universal APK에 `arm64-v8a`, `armeabi-v7a`, `x86`, `x86_64` 포함

- 기존 큐와 생성 스냅샷은 호환 decoder를 유지한다.
- Android versionCode: `2011003`

## 5. 배포·롤백

1. `main`에 릴리즈 커밋을 먼저 푸시한다.
2. 해당 커밋에 annotated tag `v2.11.3`을 생성해 푸시한다.
3. `Build & Release` workflow가 Windows/macOS 번들 및 Android signed universal APK를 만들고 draft release를 검증 후 공개한다.
4. 롤백이 필요하면 기존 공개 릴리즈 `v2.11.2` 자산을 재설치한다. 이미 공개된 태그와 자산은 교체하지 않고, 수정은 새 patch 버전으로 배포한다.

## 6. 알려진 제약과 후속 확인

- Android의 NAI 토큰은 현재 세션 전용이다. 앱을 완전히 종료하면 다시 입력해야 한다. 장기 영속화에는 Android Keystore 기반 별도 backend가 필요하다.
- 로그인된 NovelAI UI를 기준으로 비용식을 검증했지만, NovelAI가 서버 가격 정책을 변경하면 관측 fixture와 계산 상수를 함께 갱신해야 한다.
- 릴리즈 후 실제 Windows 설치 등록, Android 패키지 서명·ABI·versionCode, GitHub 자산 목록을 다시 확인한다.

## 7. 운영 인계 체크리스트

- Guided 기본 진입과 우측 상단 고급 생성 모드 전환을 확인한다.
- 한 장/여러 장 생성에서 사용자 지정 해상도와 예상 Anlas가 동일하게 표시되는지 확인한다.
- 토큰 1개에서는 생성이 직렬화되고, 서로 다른 활성 토큰 2개에서는 비스트리밍 작업이 최대 2개 실행되는지 확인한다.
- 결과 프리뷰, 실패/취소 복구, 초안 재개, R2 쓰기 검증을 확인한다.
- 공개 릴리즈의 installer, updater signature, macOS bundle, Android APK 및 checksum이 모두 존재하는지 확인한다.
