# NAI Blue v1.0.0 release handoff

Date: 2026-08-12 (Asia/Seoul)

## Release meaning

`1.0.0` resets the public version label and Git tag only. It does not reset the
feature set, persisted data, queue state, credentials, or migration history.

- Product name: `NAI Blue`
- Repository: `bluehair-blue/NAI-Blue`
- Tag: `v1.0.0`
- Desktop and Android identifier: `blue.bluehair.naiblue`
- Android version name: `1.0.0`
- Android version code: `2011004`
- Android update baseline: `v2.11.3` / `2011003`

Pre-rename serialized store and database identifiers remain compatibility ABI.
New user-facing metadata, sidecars, diagnostics, binaries, and release assets use
the NAI Blue name. The updater explicitly accepts the reset display version and
Windows updater metadata prefers NSIS.

## Publication order

1. Commit and push the NAI Blue identity, documentation, and release contract.
2. Rename the GitHub repository to `bluehair-blue/NAI-Blue` and update `origin`.
3. Create and push the immutable annotated tag `v1.0.0` from `main`.
4. Let the desktop workflow create the draft release.
5. Approve the protected Android signing environment if requested.
6. Verify all desktop, macOS, Android, updater, signature, and checksum assets.
7. Confirm the release is public and marked latest without deleting historical
   release tags.
